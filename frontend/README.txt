# EstateAI Frontend Template

Static, responsive real-estate UI demo with no backend required.

Files:
- index.html
- login.html
- register.html
- properties.html
- property-detail.html
- saved-properties.html
- chat.html
- my-visits.html
- agent-dashboard.html
- profile.html
- style.css
- app.js

Open `index.html` in a browser. Internet access is required for Google Fonts and remote Unsplash images.
